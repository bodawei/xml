Design
	call a routine
		if we can find to the end, return
		if we can't find but plenty of text, return failure
		if we can't and at buffer end and buffers done, return failure
		if we can't, but at buffer end and more buffers coming
			(optimize: if our matched-so-far bit is small enough, substr it from buffer so we can gc)
			store operation, if match store offset within matched value
	when buffer arrives:
		push buffer
		if in middle operation, then try to continue with above algorithm.
			may fail to find a match (return with failure)
			may find a match or end of extension (return the data, and discard buffer(s))
			may consume buffer but not fully find match or extend-end, in which case push and continue
